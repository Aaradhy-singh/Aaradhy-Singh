## 📌 Featured Projects

### 💧 JalRakshak: Water-Stress Awareness Platform for Varanasi

AI-grounded water-stress advisory platform built for the 1M1B internship, aligned with SDG 6 (Clean Water) and SDG 13 (Climate Action). It combines live weather and air-quality data with methodology and Responsible AI pages. Any figure that is not live or sourced is labeled illustrative on the site.

**Stack:** React · TypeScript · Tailwind CSS · Open-Meteo API · Vercel

[🌐 Live Site](https://jalrakshak-bice.vercel.app/) · [💻 Repository](https://github.com/Aaradhy-singh/jalrakshak)

<br/>

### 🚀 SpaceShield: Space & Defence News Aggregator

India-first real-time aggregator pulling from NASA APOD, Spaceflight News, and GNews, with Groq-powered (Llama 3.1 8B Instant) summarization. Fully client-side with no backend infrastructure, which keeps hosting cost low and the deployment simple.

**Stack:** React · Vite · Tailwind CSS v3 · Groq API · NASA APOD API · Spaceflight News API · GNews API

[💻 Repository](https://github.com/Aaradhy-singh/spaceshield)

<br/>

### 📄 ResumeAI Pro: Resume Diagnostic Platform

Browser-based resume diagnostic tool covering skill gaps, ATS compatibility, impact scoring, and role matching across 300+ roles. No account required, and analysis runs entirely client-side with PDF export. Built on a strict monochrome design system (black/white/navy, DM Serif Display + DM Mono, zero border-radius) to force disciplined UI decisions.

**Stack:** React · TypeScript · Vite · Tailwind CSS · shadcn/ui · jsPDF · PostHog · Formspree · Octokit

[🌐 Live Site](https://resume-ai-pro-psi.vercel.app/) · [💻 Repository](https://github.com/Aaradhy-singh/resume-ai-pro)

<br/>

### 🎓 Local AI Academic Tutor

Offline-capable AI chatbot running a local LLM through Ollama with a Gradio interface. No external API dependency and no data leaving the device, built to explore local inference tradeoffs against cloud LLM APIs: cost, latency, and privacy.

**Stack:** Python · Gradio · Ollama

[💻 Repository](https://github.com/Aaradhy-singh/local-llm-academic-tutor)

<br/>

### ✨ Gesture Particle Universe: Gesture-Controlled 3D Particles

A single-file, 9,000-particle interactive 3D system controlled entirely by hand gestures, combining computer vision with custom shader rendering. Shipped as one HTML file with no build step.

**Stack:** Three.js · MediaPipe · custom GLSL shaders

[💻 Repository](https://github.com/Aaradhy-singh/gesture-particle-universe)
